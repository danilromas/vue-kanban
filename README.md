# Доска задач (Vue Kanban)

Канбан-доска в духе Trello: колонки, карточки, перетаскивание, приоритеты и дедлайны. Всё хранится в браузере, сервер не нужен.

**Демо:** https://danilromas.github.io/vue-kanban/

![Превью](docs/preview.png)

## Что умеет

- drag & drop карточек между колонками и внутри колонки (нативный HTML5 DnD, без библиотек)
- создание, редактирование и удаление задач, приоритет, тег, дедлайн
- подсветка задач с горящим и просроченным дедлайном
- поиск и фильтр по приоритету
- свои колонки: добавить, переименовать (двойной клик по заголовку), удалить
- прогресс по доске, сохранение в `localStorage`

## Стек

Vue 3 (Composition API, `<script setup>`), Pinia, Vite, чистый CSS.

## Запуск

```bash
npm install
npm run dev
```

Сборка — `npm run build`, деплой на GitHub Pages идёт через GitHub Actions при пуше в `main`.

## Структура

```
src/
  stores/board.js        — состояние доски и вся логика (Pinia)
  components/
    BoardColumn.vue      — колонка, приём drop и плейсхолдер
    TaskCard.vue         — карточка задачи
    TaskModal.vue        — форма создания/редактирования
  utils/                 — даты и localStorage
```
